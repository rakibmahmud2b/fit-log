# FitLog

### Train with intent. Log every set.

FitLog is a responsive workout library and daily training planner. Browse workouts, view detailed exercise information, build your daily plan, and save workouts for later.

## Features

* Browse 12 workouts with images, muscle groups, equipment, duration, calories, and ratings.
* View detailed workout information with difficulty, sets, reps, and instructions.
* Add up to five workouts to Today's Plan.
* Save workouts for later.
* Track exercises, total minutes, and calories.
* Mark workouts as done and remove them from the plan.
* Sort workouts by duration, calories, or rating.
* Persist plan, saved, and completion data using localStorage.
* Fully responsive for mobile, tablet, and desktop.

## Technologies Used

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS 4
* Lucide React
* REST API
* Local Storage
